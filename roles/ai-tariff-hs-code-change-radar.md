# AI 关税与 HS 编码变更雷达｜AI Tariff & HS Code Change Radar

## 一句话定位

它每天帮跨境老板盯公开税则、HS 编码和重点 SKU，把可能影响报价、毛利、清关的变化提前列出来，交给销售、财务和报关行确认。

## 适合谁

- 有美国、欧盟、英国等主要出口市场的外贸工厂和跨境电商公司。
- SKU 多、材质/用途变化多、报价经常要考虑关税和清关成本的团队。
- 老板、财务、报关、供应链和销售经常为“这个税率还准不准”“这个编码还能不能用”反复确认的公司。

## 老板痛点

关税最麻烦的地方，不是税表复杂，而是它常常在报价后、发货前、清关时才变成问题。销售已经把价格报给客户，运营已经把活动排好，财务才发现某个 HS 编码、附加税或目的国规则可能有变化。

轻则毛利被吃掉，重则清关被卡、客户要求重算价格。老板真正需要的不是一堆政策原文，而是一张今天能不能继续按旧税率报价的提醒表。

## 岗位职责

AI 关税与 HS 编码变更雷达每天接收三类输入：

1. 脱敏 SKU 表：品名、材质、用途、目标市场、当前 HS 编码、近 30 天出货金额区间、毛利区间。
2. 公开税则和政策页面：USITC HTS、EU TARIC、英国税则、WITS 或其他政府/官方来源。
3. 人工维护的重点关注清单：高毛利 SKU、高出货 SKU、近期报价 SKU、报关行提醒过的敏感品类。

它每天输出一页“关税影响提醒表”：哪些 SKU 的税则页面、税率、附加说明、归类描述或目的国要求出现变化；可能影响哪个市场、哪批报价、哪条产品线；需要销售、财务、报关行或老板确认什么。

它不是自动归类工具，也不是税务顾问。它的价值在于：在报价和发货前，把容易吃掉毛利或卡清关的线索提前翻出来。

## 可接手任务

1. 维护 SKU 与 HS 编码、材质、用途、目标市场的映射表。
2. 每天检查重点市场税则页面和公开公告是否有变化。
3. 把变化翻译成老板能看懂的提醒：可能影响报价、毛利、清关还是资料准备。
4. 标记高风险 SKU：高出货、高毛利、近期报价、历史清关问题多的品类。
5. 生成“需要报关行确认的问题清单”。
6. 给销售准备报价前提醒：这类产品本周先别直接套旧税率。
7. 给财务准备 landed cost 复算清单。
8. 记录每次人工确认结果，形成可追溯日志。

## 工作机理

```text
脱敏 SKU 表 / 当前 HS 编码 / 目标市场 / 近期报价
        ↓
公开税则监控：USITC、TARIC、英国税则、WITS、政府公告
        ↓
变化比对：税率、附加说明、商品描述、目的国要求
        ↓
影响匹配：哪些 SKU、报价、市场、毛利区间可能受影响
        ↓
行动清单：销售暂停套旧价 / 财务复算毛利 / 报关行确认归类
        ↓
人类主管验收：老板看金额和优先级，财务/报关确认最终判断
```

## 可复制提示词

### 1. SKU-HS 风险初筛

```text
你是跨境公司的关税与 HS 编码变更雷达。请根据下面的脱敏 SKU 表，找出最需要优先人工复核的产品。

输入字段：sku_id、产品英文名、材质、用途、目标市场、当前 HS 编码、近 30 天出货金额区间、毛利率区间、最近报价日期。

输出表格字段：sku_id、目标市场、当前 HS 编码、为什么要优先复核、需要补充的资料、建议找谁确认（销售/财务/报关行/产品）、风险等级高/中/低。

规则：不要给最终 HS 归类结论；不要承诺税率正确；只输出需要人工确认的线索。

数据：{{脱敏 SKU_HS_mapping_table}}
```

### 2. 税则页面变化翻译成老板提醒

```text
下面是某个 HS 编码或税则页面的新旧文本差异。请把它翻译成老板能看懂的一页提醒。

输出：
1. 变化发生在哪个市场/编码/品类；
2. 可能影响哪些业务动作：报价、毛利、清关资料、客户沟通、发货时间；
3. 今天必须确认的 3 个问题；
4. 不能直接下结论的地方；
5. 建议发给销售、财务、报关行的短消息草稿。

限制：不要写“确定涨税/确定降税”，除非输入里有明确官方数字；含糊处统一写“需报关行或财务确认”。

新旧差异：{{tariff_page_diff}}
```

### 3. 报价前关税检查清单

```text
请为下面这批准备报价的 SKU 生成报价前关税检查清单。

输出表格：sku_id、目标客户国家、当前 HS 编码、最近一次确认日期、是否超过 30 天未确认、需要销售补充的信息、需要财务/报关确认的问题、报价风险提示一句话。

规则：不计算最终税费，不替代报关行意见；只提醒销售不要直接套旧模板报价。

数据：{{quote_sku_list}}
```

### 4. landed cost 复算任务单

```text
请把下面的关税/税则变化线索转成财务可执行的复算任务单。

输出：影响市场、SKU 范围、需要复算的成本项、优先级、需要谁提供数据、复算前不得做的业务动作、复算后老板要看的指标。

限制：不要输出客户报价或承诺；不要使用供应商合同、采购价、客户名等敏感信息。

线索：{{tariff_change_watchlist}}
```

## 第一周试点

- **Day 1：选范围**。只选 1 个目标市场、20–50 个高出货 SKU；整理品名、材质、用途、当前 HS 编码、近 30 天出货金额区间。
- **Day 2：建关注表**。标出高毛利、高出货、近期报价、历史清关问题 SKU；补齐报关行联系人和财务复核人。
- **Day 3：接公开来源**。先用人工下载/网页 diff/n8n 监控 USITC 或 TARIC 等公开页面，不接内部敏感系统。
- **Day 4：跑第一版提醒**。输出“可能受影响 SKU + 需要确认问题 + 建议负责人”。
- **Day 5：人工复核**。报关行/财务抽查所有高风险项，回填确认结果，删掉误报规则。
- **Day 6：接报价前检查**。让销售在新报价前先查这张提醒表。
- **Day 7：老板验收**。只看三件事：提前发现了几个风险 SKU，避免了几次套旧税率报价，哪些规则需要继续人工维护。

## 人类主管验收

老板 / 财务 / 报关负责人每天只看：

1. 今天新增哪些高风险 SKU，是否有官方来源链接或截图。
2. 哪些报价、发货或毛利复算要先暂停确认。
3. 每条提醒是否分配给销售、财务、报关行或产品负责人。
4. AI 是否把不确定问题标成“需人工确认”，而不是装作有最终答案。
5. 误报和漏报有没有回填，明天规则是否变得更准。

## 不能自动化的事

- 不自动做最终 HS 归类，不替代报关行、财务、税务顾问或律师意见。
- 不自动向海关、平台、客户或承运商提交申报、报价、合同、承诺或解释。
- 不使用客户名、合同、采购价、真实报价、供应商底价、平台账号 token、报关单原件等敏感信息做公开示例。
- 不把公开网页变化直接写成“确定涨税/确定违规”；低置信度必须进入人工复核。
- 不绕过政府网站、平台或数据服务的访问限制、验证码、登录权限或条款。
