# AI 产品认证到期提醒员

> 每天替老板盯住 SKU、证书、供应商、复核日期、文件夹和负责人，别等平台审核、客户资料包或发货前才发现证书缺了、过期了、型号对不上。

## 岗位名

- 中文：AI 产品认证到期提醒员
- English：AI Product Certification Expiry Reminder

## 适合谁

- 跨境贸易公司、外贸工厂、DTC 独立站、Amazon / eBay / Walmart / Temu / TikTok Shop 等平台卖家。
- 产品涉及电子电器、玩具、家居小电、灯具、无线设备、电源适配器、消费电子、户外装备、母婴用品等。
- 经常被客户、平台、海关、海外仓或保险公司要求补 CE、FCC、RoHS、REACH、MSDS、UN38.3、测试报告、符合性声明。
- SKU 多，证书散落在业务员、工程师、供应商、质检、老板微信和网盘里的团队。

## 老板痛点

客户要资料包，平台要审核，货要发出去，团队才发现证书散在不同人的网盘、微信、供应商邮件和旧文件夹里。证书有没有过期、型号是否覆盖、缺口归谁补，没有人每天盯。

## 岗位描述

这个数字员工负责建立和维护产品认证资料台账，对每个 SKU、型号、销售市场、证书类型、文件来源、负责人、到期时间、复核时间、缺口状态做持续跟踪。

它不会判断产品一定合规，也不会替代检测机构、律师、税务或合规顾问。它只帮老板看清：证书在哪里、哪些产品缺证书、哪些文件快到期、哪些型号需要人工确认、哪些资料该找谁补。

## 可接手任务

1. 建立 SKU 认证资料台账。
2. 按 90 / 60 / 30 / 7 天提醒快到期证书。
3. 检查 CE / FCC / RoHS / REACH / MSDS / UN38.3 是否缺文件。
4. 标记证书覆盖型号和销售 SKU 疑似不匹配。
5. 按客户或平台要求准备资料包缺口清单。
6. 把缺口分派给采购、工程、质检、业务、运营。
7. 记录供应商资料追踪进度。
8. 每周生成老板风险摘要。

| 模块 | 具体动作 | 公开工具 / Skill 线索 |
|---|---|---|
| 证书识别 | 读文件标题、日期、型号、报告编号、签发方 | Paperless-ngx、OCR、文档解析 |

| 资料包整理 | 列出已有文件、缺失文件、文件夹路径和待人工确认项 | Outline、Plane、共享文件夹 |

## 工作机理

```text
SKU 表 + 证书文件 + 供应商资料 + 客户/平台要求
→ 抽取证书类型、型号、日期、路径、负责人
→ 建产品认证台账
→ 每天检查快到期、缺文件、型号疑似不匹配、无人负责
→ 生成提醒和资料包缺口清单
→ 人类主管 / 检测机构 / 合规顾问确认最终结论
```

## 可复制提示词

```text
请检查今天的产品认证台账。按 SKU 列出 30 天内到期的证书、缺失的证书文件、对应供应商、负责人和网盘文件夹路径。请单独标记会影响平台审核、客户资料包、发货的事项。不要做最终合规判断，不要替检测机构下结论，不要承诺客户一定通过。
```

```text
请从以下证书/测试报告文本中提取：文件类型、产品名称、SKU、报告覆盖型号、申请人/制造商、签发机构、报告编号、签发日期、到期日期、适用标准、需要人工确认的问题。只提取文件中明确出现的信息，没有的写“未找到”。
```

```text
请根据 SKU 表和证书覆盖型号，标记“疑似匹配 / 疑似不匹配 / 需要人工确认”。你不能下合规结论，不能判断产品是否可以销售，也不要编造型号关系。最后列出建议询问供应商的问题。
```

## 人类主管验收

老板每天看：无人负责的证书数量、30 天内到期或需复核的高风险 SKU 数量、客户资料包缺口、供应商未回复事项。采购、工程、质检、业务各自抽查 AI 标记是否准确。最终合规结论必须由人类主管、检测机构或专业顾问确认。

## 不能自动化的事

- 不替代检测机构出具报告。
- 不替代律师、税务师、合规顾问做专业判断。
- 不伪造、修改、拼接、PS 证书。
- 不自动承诺客户“产品完全合规”。
- 不自动上传客户隐私、报价、合同、订单信息到外部 AI 工具。
- 不判断“这个产品一定可以进入欧盟 / 美国市场”。
- 不把 CE、FCC、RoHS、REACH 简化成一个通用“合规通过”标签。

## 第一周试点方案

- Day 1：选 20 个高风险在售 SKU，优先爆款、近期发货、客户索要过证书、电子电器或平台审核频繁的产品。
- Day 2：集中现有证书和供应商资料到一个文件夹。
- Day 3：抽取证书类型、型号、报告编号、签发 / 到期 / 复核日期、负责人。
- Day 4：建立 NocoDB / 飞书多维表格 / Excel 台账。
- Day 5：跑第一版缺口清单和 30/60/90 天提醒。
- Day 6：把缺口分给采购、工程、质检、业务、运营；AI 记录状态，不替人拍板。
- Day 7：老板看一页报告，决定是否扩到更多 SKU。

## 风险分级

- 内容安全：PASS，使用公开资料和脱敏试点设定。
- 隐私：不得上传客户姓名、电话、地址、报价、合同、付款和内部利润数据。
- 合规：仅做台账、提醒、缺口清单和负责人追踪，不替代检测机构或合规顾问。
- 发布：外部正式发布仍需郝敬确认。
