# AI 老客户复购提醒员

> 面向出海老板的数字员工岗位地图：把“买过一次却没再下单”的客户从订单表里捞出来，交给运营或销售人工确认。

## 1. 岗位名

- 中文：AI 老客户复购提醒员
- English：AI Repeat Buyer Reactivation Assistant

## 2. 适合谁

- DTC 独立站，有耗材、配件、季节款、复购款。
- 外贸小 B / 经销商业务，有样品转订单、老客户返单场景。
- 老板感觉新客很贵，但老客户运营没人专门盯。
- 已有 Shopify / WooCommerce / ERP 订单导出，但 CRM 节奏不稳定。

## 3. 老板痛点

很多团队每天都在追新客：投广告、找红人、跑展会、发开发信。可买过一次的人，常常就躺在订单表里。谁上次买的是耗材？谁可能该补配件？谁三个月没动静但曾经客单价很高？销售靠记忆，运营靠感觉，老板只在月底看见复购率低。

## 4. 岗位描述

这个数字员工每天接收脱敏订单、网站行为和业务规则，产出一页“今日复购提醒表”。它不替公司发消息，只告诉团队：今天该联系哪些老客户、为什么联系、适合提醒什么、由谁确认、哪些人暂时不要碰。

## 5. 可接手任务

1. 找出 30/60/90 天未复购客户。
2. 按国家、品类、购买次数、客单价分组。
3. 标出补货、配件、新品、换季提醒机会。
4. 剔除退货、投诉、拒付、退订客户。
5. 写邮件 / 客服备注 / 销售跟进的草稿。
6. 把名单分派给运营或销售。
7. 每天统计触达后的打开、点击、询盘、下单变化。
8. 每周复盘哪些分组值得继续做。

## 6. 能力模块

- 订单分层：从 Shopify / WooCommerce / ERP 导出订单，把老客户分成可联系、需确认、暂不联系。
- 复购窗口：按品类周期、季节、耗材/配件关系，判断今天为什么值得提醒。
- 触达草稿：生成邮件、私信、客服备注的第一版，但不自动发送。
- 工作流分派：用 n8n 把名单推给运营、销售或飞书群。
- 结果看板：用 Metabase、PostHog、Umami 看触达后的访问、点击和订单变化。

## 7. 工作机理

```text
脱敏订单 + 行为信号 + 业务规则
  → 清理不可触达名单
  → 按品类 / 时间 / 国家分组
  → 判断复购窗口
  → 写联系理由和草稿
  → 今日复购提醒表 + 负责人 + 老板抽查样本
```

人工验收：老板看名单是否合理，运营看话术是否克制，销售看高客单客户是否需要人工判断。

## 8. 真实任务示例 / 提示词

```text
请分析这份已脱敏订单表，找出最近 30/60/90 天没有复购、但上次购买品类有补货或配件机会的客户分组。只输出客户编号、国家、上次购买品类、可能联系原因、建议负责人，不要生成真实姓名、邮箱或电话。
```

```text
请根据这 20 条老客户购买记录，为邮件运营写 3 个复购提醒角度。要求像真人客服提醒，不承诺折扣、不承诺库存和交期，每个角度说明适合哪类客户。
```

```text
请把这份老客户名单分成“今天可联系 / 需要人工确认 / 暂不联系”三类。退货、投诉、拒收、取消订阅、付款争议客户必须放入人工确认或暂不联系，并说明原因。
```

```text
请把昨天的复购提醒触达结果整理成老板早报：发送人数、打开/点击/询盘/下单变化、最有效分组、需要停止的话术、今天建议只做的 3 个动作。
```

## 9. 人类主管验收

- 每天抽查 20–30 条名单，看推荐理由是否真实。
- 每组客户至少看 5 条样本，确认品类、周期、国家、话术匹配。
- 高客单、投诉、退货、拒付、取消订阅客户必须人工确认。
- 每周只看 4 个结果：回复、询盘、加购、订单；同时看退订和投诉有没有上升。

## 10. 不能自动化的事

- 不自动发送邮件、私信、WhatsApp 或 LinkedIn 消息。
- 不自动承诺折扣、库存、交期、样品、赔偿或独家价格。
- 不使用真实客户名、邮箱、电话、订单号、合同、报价单、支付信息作为公开素材。
- 投诉、拒付、退货、合规、敏感国家/地区客户必须人审。

## 11. 第一周试点方案

- Day 1：只选一个店铺或一个品类，导出最近 12 个月脱敏订单。
- Day 2：定 30/60/90 天三个复购窗口，列出不可触达名单。
- Day 3：生成第一版复购提醒名单，人工抽查 30 条。
- Day 4：只给一个客户分组写触达草稿，不自动发送。
- Day 5：运营或销售人工小样本发送，记录回复与退订。
- Day 6：整理哪些理由有效，哪些话术太硬。
- Day 7：老板看一页复盘，再决定是否扩大到第二个品类。

|---|---|---|---|
| n8n | 把订单导出、分群、提醒、任务分派串成流程 | 有基础技术同事的团队 | 不自动发送高风险消息 |
