# AI TikTok Shop 商品页体检员

> 每天检查 TikTok Shop 商品页的标题、图片、描述、类目、价格/促销、评价反馈和政策红线，给老板一张“今天先修哪些 SKU”的清单。

## 适合谁

- 正在做 TikTok Shop US / UK / 东南亚站点的跨境卖家。
- SKU 多、上新快、运营和美工经常返工的团队。
- 老板每天追问“哪个商品页最该先修”的团队。
- 广告和短视频有流量，但商品页转化和评分拖后腿的团队。

## 老板痛点

TikTok Shop 团队常见的问题很碎：标题像关键词仓库，买家看不懂；图片少、糊、有水印，美工不知道先补哪张；描述漏了尺寸、材质、配件，客服和差评一起补锅；价格、优惠、标题和图片里的说法不一致，还可能踩到平台红线。老板问“今天到底先修哪个 SKU”，运营只能临时翻后台。

## 这个数字员工每天做什么

输入：脱敏 SKU 表、商品页截图、标题/描述/属性、价格促销、低星评价摘要、官方规则链接。  
处理：先按官方规则检查字段，再找矛盾、缺项和疑似红线，最后按风险和生意影响排序。  
输出：一张给运营、美工、供应链和老板看的“今日商品页修复清单”。

清单里应包含：SKU、问题、证据、建议改法、负责人、截止时间、是否需要人工确认。

## 可接手任务

1. 批量检查标题是否清晰、真实、符合当地语言。
2. 检查图片数量、清晰度、水印、文字、场景、尺寸和配件展示。
3. 找出描述、属性、包装清单里的缺项。
4. 检查类目、品牌、标题、图片、属性是否互相矛盾。
5. 标记价格、划线价、优惠文案和图片文字冲突。
6. 对禁售、受限、疗效、儿童安全、品牌/IP 等疑似风险做 P0 提醒。
7. 把低星评价里的抱怨转成商品页修复建议。
8. 按风险、销售影响和易修复程度排出今日 Top 20。

## 能力模块

| 模块 | 具体做什么 | 公开线索 |
|---|---|---|
| 官方规则体检 | 把 TikTok Shop PDP、Listing、Policy 规则拆成检查项 | TikTok Shop Academy |
| 标题与描述 QA | 检查标题、描述、属性和促销词 | ChatGPT / Claude / Gemini 结构化输出 |
| 图片与截图检查 | 发现少图、低清、水印、缺角度、缺尺码 | Playwright、OCR、视觉模型 |
| 评价回流 | 从脱敏低星评价里找页面应该提前说明的问题 | Product Ratings 导出 |
| 修复清单排序 | 按 P0 风险、高曝光、Poor/Fair、低星反馈和易修复程度排序 | 飞书多维表、NocoDB、表格工作流 |

## 可复制提示词

```text
你是 TikTok Shop 商品页体检员。请只基于我提供的脱敏数据检查，不要编造产品信息。请输出严重级别(P0/P1/P2/P3)、问题类型、证据、为什么影响商品页、建议修复、是否需要人工确认。
输入：SKU、类目、品牌、标题、价格/促销、图片说明或OCR、描述、属性、脱敏评价摘要。
```

```text
请审核以下 TikTok Shop 商品标题。规则：标题必须真实、可读、符合当地语言；避免折扣、库存、主观夸张、无关关键词、变体列表、医疗/绝对化承诺。不要添加输入里没有证据支持的卖点。输出：sku, pass_fail, issue_reason, suggested_title_1, suggested_title_2, human_check_required。
```

```text
请把以下脱敏低星评价摘要转成商品页修复建议。不要处理买家个人信息，不要生成客服回复；只判断商品页哪里应该说得更清楚。输出：评论问题主题、可能对应的商品页缺口、建议修改标题/图片/描述/属性/FAQ、是否可能是真实产品质量问题、负责人建议。
```

## 第一周试点

- Day 1：选 50 个 SKU，只用脱敏导出表、公开截图和脱敏评价摘要，建检查项。
- Day 2：跑 20 个 SKU 样本，运营抽查误报和漏报，定 P0/P1/P2/P3。
- Day 3：做标题和描述专项，生成候选改法，人工只批准真实卖点。
- Day 4：做图片和属性专项，列出补拍、换图、补尺寸、补配件清单。
- Day 5：做政策和价格专项，疑似红线只提醒，不自动改价或下架。
- Day 6：把低星评价映射到商品页修复项。
- Day 7：复盘体检 SKU 数、发现问题数、P0/P1 数、已修复数、待拍图数、标题通过率、描述缺失率、图片问题率。

## 人类主管验收

老板每天看 4 件事：今天必须先修的 Top 20 SKU；P0/P1 风险是否有人接单；标题、图片、描述、评价回流各自修了多少；哪些建议需要老板、法务、供应链或品牌负责人拍板。

## 不能自动化的事

- 不自动改价、下架、提交商品页或批量修改 Seller Center。
- 不做法律、平台合规、认证、召回和品牌/IP 的最终判断。
- 不凭空补规格、材质、认证、功效、配件或产地。
- 不处理买家姓名、电话、地址、订单号、支付信息、利润、合同、报价等敏感信息。
- 不代表品牌承诺退款、赔偿、售后或时效。

## 相关 Skill / repo / 工作流

1. TikTok Shop Academy PDP & Listing Quality：官方检查项来源；风险是站点和类目规则会变，最终以后台最新政策为准。
2. TikTok Shop Product Listing Policy：红线初筛；风险是 AI 不能替代平台和法律判断。
3. Great Expectations — https://github.com/great-expectations/great_expectations：校验 CSV 字段完整性、空值、长度、格式；风险是只用脱敏导出。
4. OpenAI Cookbook — https://github.com/openai/openai-cookbook：参考结构化输出、批处理、图片/文本抽取；风险是所有建议必须有输入证据。
5. Microsoft Playwright — https://github.com/microsoft/playwright：在授权页面或公开截图场景采集页面证据；风险是不绕过登录、验证码或平台反爬。

## 风险分级

- 内容安全：PASS，使用公开资料和脱敏试点设定。
- 隐私：不得上传买家、订单、支付、联系方式和内部利润数据。
- 发布：外部发布仍需郝敬确认。
